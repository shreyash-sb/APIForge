==================================================
PART 10 — SECURITY
==================================================

Because the backend will make requests to URLs supplied by users, treat this as an API proxy.

Implement reasonable security protections.

At minimum:

- Only allow HTTP and HTTPS protocols.
- Validate URLs server-side.
- Never execute shell commands from user input.
- Never interpolate user input into shell commands.
- Do not log authorization tokens.
- Do not log passwords.
- Do not expose backend environment variables.
- Do not return internal server stack traces to the frontend.
- Validate request payloads.
- Handle oversized request bodies appropriately.

IMPORTANT FOR DEVELOPMENT:

The application needs to be able to test local APIs during development.

Therefore, do not blindly block localhost/127.0.0.1 if that would prevent testing local development APIs.

If SSRF protection is implemented, structure it so it can be strengthened later without breaking legitimate local API testing.

Clearly separate development-mode behavior from production security behavior where necessary.
